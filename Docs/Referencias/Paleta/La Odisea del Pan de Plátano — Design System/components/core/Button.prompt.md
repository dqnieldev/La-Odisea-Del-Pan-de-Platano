Botón principal de menús y diálogos (Jugar, Reintentar, Continuar); amarillo plátano para la acción más importante.
```jsx
<Button variant="primary" size="lg" icon="play_arrow">Jugar</Button>
<Button variant="secondary">Opciones</Button>
```
- Variantes: primary (plátano), secondary (blanco), mangrove (verde), dark (café/plátano), ghost.
- Presionado: fondo más oscuro + baja 2px + escala .96. Disabled: beige apagado.
