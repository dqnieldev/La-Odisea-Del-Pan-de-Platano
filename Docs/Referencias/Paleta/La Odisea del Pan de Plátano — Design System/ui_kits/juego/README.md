# UI kit — Juego (PC, 1920×1080)
Recreación de las pantallas del juego según el documento de proyecto (MVP + HU-01…06). No había mockups de UI in-game en las fuentes; el layout del HUD se deriva de los requerimientos (vidas, puntuación/tiempo, barra de cocción) y de la paleta/componentes de *Interfaz gráfica*.
- `Menu.jsx` — Menú principal (Jugar, Opciones, Salir) con los arcos de la portada.
- `WorldMap.jsx` — Mapa "La Ruta del Pan" con nodos de nivel y panel de detalle.
- `Level.jsx` — Nivel con HUD, casillas de ingredientes, Pausa (P/Esc), Game Over y Victoria.
Fondo del Nivel 3: no hay arte del manglar en side-scroll; se usa un recorte del mapa como placeholder.
